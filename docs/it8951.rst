IT8951
===============

Patching
--------

We use meson to download appropriate driver version and patch it to make driver usable by ebook reader.
Main customizations that we did are related to adding stm32mp135f support and optimizing performance.

The procedure of creating the patch for it8951 is somwhat not straiforward so next we will walk threw it.
First you need to git clone appropriate it8951 version:

.. code-block:: console

   $ git clone https://github.com/waveshareteam/IT8951-ePaper.git it8951
   $ cd it8951

Next we need to apply our current patch to the new repo.

.. code-block:: console

   $ patch < ../stm32mp135f/ebook_reader/subprojects/packagefiles/it8951/00.patch

Now make chenges to the repo, and once you're done create a new patch:

.. code-block:: console

   $ git diff > ../stm32mp135f/ebook_reader/subprojects/packagefiles/it8951/01.patch

Last thing is to add this new patch to it8951.wrap to property diff_files.
